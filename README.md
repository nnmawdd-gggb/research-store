# 📚 متجر الأبحاث - Research Store

متجر إلكتروني حديث متخصص في بيع الأبحاث العلمية والأكاديمية

## المميزات ✨

- 🎨 تصميم جميل وحديث
- 📱 متوافق مع جميع الأجهزة
- 🛒 نظام سلة تسوق فعال
- ⚡ سريع جداً بفضل Next.js
- 🌍 واجهة عربية كاملة

## التثبيت والتشغيل 🚀

```bash
# تثبيت المكتبات
npm install

# تشغيل الخادم الإنمائي
npm run dev

# سيفتح الموقع على http://localhost:3000
```

## البناء للإنتاج 📦

```bash
npm run build
npm start
```

## الملفات الأساسية 📂

- `pages/` - صفحات التطبيق
- `components/` - المكونات المعاد استخدامها
- `store/` - إدارة الحالة (Zustand)
- `styles/` - أنماط CSS
